### Surprise of the day

Fixing the audit script's default target from `.agent/skills` to `.claude/skills` immediately surfaced an `ERROR` on `mps-booking-system/SKILL.md`: the file had no YAML frontmatter at all. The audit had been silently passing this skill for months because the misconfigured default never pointed at `.claude/skills`. **Tooling that runs but checks the wrong thing is worse than no tooling.** Frontmatter was added in the same commit as the default-target fix, so the script went from "133 warnings + 0 errors" to "0 warnings + 0 errors" in one step.

### Wix split rationale

The persona was 152 lines mixing four rate-of-change profiles:

- Decision rules (slow-changing) — stayed in `.claude/agents/wix-headless-agent.md`
- Account state and dashboard URLs (medium-changing) — moved to `docs/wix-headless-reference.md` with a "Last verified: 2026-05-01" stamp and an explicit Update protocol

The persona now declines to mention dollar amounts or `import` statements. If those facts change, only one file needs editing.
